# College & Course Additional Information

Admissions Administration now contains two separate rich-content modules:
- College Additional Information
- Course Additional Information

Each supports selecting the College/Course, additional text, video URL, brochure PDF upload, multiple gallery images, placement information, rank/ranking information, and Active status.

The existing College and Course CRM forms remain simple. Rich information is displayed automatically on the existing public detail pages, followed by the existing Apply Now / Free Counselling action.

Run:
`python manage.py migrate`
`python manage.py runserver`
