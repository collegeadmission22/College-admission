# Admissions Administration Update

- Search bars no longer show category dropdown filters.
- Apply form is compact: Row 1 Student/Father, Row 2 Mobile/Email, Row 3 Course/College.
- Apply submissions continue to create/update Website leads by mobile number.
- New editable Admissions Administration master lists: Countries, States, University Names, College Categories, Course Categories.
- Course Names remain managed in Courses and support Add / Change / Delete in Django Admin.

After updating the project run:
`python manage.py migrate`
`python manage.py runserver`
